# งาน Fttr

ชุดตั้งต้นอยู่ใน `dataset_7class_balanced` และ `dataset_cls` ใช้ `dataset_7class_balanced/data.yaml` และ `split_report.md` ตรวจชุด train/val และชื่อคลาส

ยังไม่ได้สร้างโปรเจกต์ Label Studio สำหรับ Fttr เพราะไม่มี XML หรือ JSON เฉพาะงานนี้ในคำขอ
เริ่มบริการรวมได้ด้วย `../labeling/START.cmd`; คู่มืองานที่เตรียมให้แล้วอยู่ใน Savety, Splitter และ Cable-sagging
ไม่มีการเปลี่ยนรูปหรือ labels ของชุด Fttr
